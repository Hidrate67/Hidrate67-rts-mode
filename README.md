# rts-mode

Top-down RTS-style FiveM game mode scaffold. Server-authoritative AI squads capture zones and players issue tactical orders through an NUI minimap.

Quick start for Nodecraft:
1. Create a FiveM server on Nodecraft (fxserver template).
2. Obtain a FiveM license key at https://keymaster.fivem.net and add it to server.cfg: sv_licenseKey "YOUR_KEY"
3. Upload this resource folder to resources/rts-mode
4. Add `start rts-mode` to server.cfg and restart the server

This repo contains a minimal scaffold (server/client/NUI) and design docs. I'll iterate features and open issues on the dev branch.
